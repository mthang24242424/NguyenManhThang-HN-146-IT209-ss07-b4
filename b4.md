# Bài 4: Cấu hình Reverse Proxy Nginx cho ứng dụng Spring Boot

## Mục tiêu

- Cấu hình Nginx Server Block làm Reverse Proxy định tuyến lưu lượng mạng.
- Dùng Path Matching để phân tách lưu lượng tĩnh (static) phục vụ trực tiếp và lưu lượng động (dynamic) chuyển tiếp đến Spring Boot backend.

---

## Bối cảnh

Hệ thống cần:
- Phục vụ trang chủ tĩnh tại `/` qua cổng `80`.
- Chuyển tiếp toàn bộ request có tiền tố `/api/` đến ứng dụng Spring Boot chạy tại `http://127.0.0.1:8082`.

---

## Quy trình thực hiện

### Bước 1: Tạo trang tĩnh index.html

Tạo thư mục (nếu chưa có) và viết file `index.html`:

```bash
sudo mkdir -p /var/www/html
```

```bash
sudo tee /var/www/html/index.html > /dev/null <<EOF
<!DOCTYPE html>
<html lang="vi">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Trang chủ</title>
</head>
<body>
    <h1>Thông tin học viên</h1>
    <p><strong>Họ và tên:</strong> Nguyễn Văn A</p>
    <p><strong>Mã lớp:</strong> DevOps-K01</p>
</body>
</html>
EOF
```

---

### Bước 2: Tạo file cấu hình Nginx

Tạo file cấu hình tại `/etc/nginx/sites-available/spring-proxy.conf`:

```bash
sudo tee /etc/nginx/sites-available/spring-proxy.conf > /dev/null <<'EOF'
server {
    listen 80;
    server_name _;

    # --- Static Serve: phục vụ trang tĩnh tại / ---
    location / {
        root /var/www/html;
        index index.html;
        try_files $uri $uri/ =404;
    }

    # --- Reverse Proxy: chuyển tiếp /api/ đến Spring Boot ---
    location /api/ {
        proxy_pass         http://127.0.0.1:8082/;
        proxy_http_version 1.1;

        # Chuyển tiếp thông tin client cho backend nhận diện đúng
        proxy_set_header   Host             $host;
        proxy_set_header   X-Real-IP        $remote_addr;
        proxy_set_header   X-Forwarded-For  $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;

        # Timeout
        proxy_connect_timeout 60s;
        proxy_read_timeout    60s;
        proxy_send_timeout    60s;
    }
}
EOF
```

---

### Bước 3: Kích hoạt cấu hình bằng symlink

Tạo liên kết mềm từ `sites-available` sang `sites-enabled`:

```bash
sudo ln -s /etc/nginx/sites-available/spring-proxy.conf /etc/nginx/sites-enabled/
```

> Nếu đã tồn tại symlink cũ thì xóa trước: `sudo rm /etc/nginx/sites-enabled/spring-proxy.conf`

## Nội dung file spring-proxy.conf (hoàn chỉnh)

```nginx
server {
    listen 80;
    server_name _;

    # Static Serve
    location / {
        root /var/www/html;
        index index.html;
        try_files $uri $uri/ =404;
    }

    # Reverse Proxy đến Spring Boot
    location /api/ {
        proxy_pass         http://127.0.0.1:8082/;
        proxy_http_version 1.1;

        proxy_set_header   Host              $host;
        proxy_set_header   X-Real-IP         $remote_addr;
        proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;

        proxy_connect_timeout 60s;
        proxy_read_timeout    60s;
        proxy_send_timeout    60s;
    }
}
```

---

## Giải thích cấu hình

| Directive | Ý nghĩa |
|-----------|---------|
| `listen 80` | Lắng nghe trên cổng 80 (HTTP mặc định) |
| `server_name _` | Bắt tất cả hostname (wildcard) |
| `location /` | Khớp mọi request, phục vụ file tĩnh |
| `root /var/www/html` | Thư mục gốc chứa file tĩnh |
| `try_files $uri $uri/ =404` | Tìm file → thư mục → trả 404 nếu không có |
| `location /api/` | Khớp request bắt đầu bằng `/api/` |
| `proxy_pass http://127.0.0.1:8082/` | Chuyển tiếp request đến Spring Boot |
| `proxy_set_header Host $host` | Giữ nguyên hostname gốc của client |
| `proxy_set_header X-Real-IP $remote_addr` | Truyền IP thực của client cho backend |
| `proxy_set_header X-Forwarded-For` | Chuỗi IP khi đi qua nhiều proxy |
| `proxy_set_header X-Forwarded-Proto` | Giao thức gốc (http/https) |

---

## Sơ đồ luồng hoạt động

```
Client
  │
  ▼
Nginx (port 80)
  │
  ├── GET /         →  /var/www/html/index.html  (Static)
  │
  └── GET /api/**   →  http://127.0.0.1:8082/    (Reverse Proxy)
                              │
                              ▼
                     Spring Boot (app.jar)
```

---

## Lưu ý

- **`proxy_pass` có dấu `/` ở cuối**: khi dùng `proxy_pass http://127.0.0.1:8082/`, Nginx sẽ strip phần `/api/` trước khi chuyển tiếp. Ví dụ: request `/api/health` → backend nhận `/health`.
- **Không có dấu `/` ở cuối** (`proxy_pass http://127.0.0.1:8082`): backend nhận nguyên `/api/health`. Chọn cách phù hợp với cấu trúc API của Spring Boot.
- Đảm bảo không có file cấu hình mặc định (`default`) trong `sites-enabled` xung đột với `spring-proxy.conf` trên cổng 80.
